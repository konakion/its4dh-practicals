A wearable platform called **PulseBridge** receives activity uploads. Some attempts
failed. You are the support analyst: explore a supplied snapshot and write a short,
evidence-based incident note. You will not connect to a real wearable or server.

By the end you can navigate a Linux directory tree, inspect files without changing
them, filter and count events, save evidence, and explain where the shell and kernel fit.

## Recall before typing

Without notes: What does an OS do? What does the kernel manage? Why can an
application not simply access any hardware it wants? Discuss with a partner.

The CPU executes instructions; memory holds active code and data. The OS manages
resources and mediates access. Today's commands make these abstract ideas visible.
