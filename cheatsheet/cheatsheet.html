02Look at processes

ps

List processes; -o picks the columns. Filter with grep.

ps -o pid,ppid,user,comm ps -o pid,args | grep monitor

$$ / $PPID / pidof

PID of your shell, PID of its parent, PID of a program by name.

echo $$ $PPID pidof monitor

top

Busiest processes first (%CPU). Live view: press q to quit.

top -b -n 1 | head -n 12

-b -n 1: one snapshot (batch mode), needed in the browser Linux.

/proc/PID/status

What the kernel knows: State (R running, S sleeping), PPid, Threads.

grep -E 'State|PPid|Threads' /proc/$$/status

03Start and stop

& / $! / jobs / fg

Run in the background, PID of the last background job, list jobs, bring the latest one back.

monitor bed-03 & echo $! jobs fg fg %2 picks job 2

In a real terminal: Ctrl+Z pauses the foreground program, bg continues it in the background.

kill / kill -9

CommandSignalWhat the program can do
kill PIDSIGTERM (15)catch it, save, clean up, exit
kill -9 PIDSIGKILL (9)nothing: removed at once

Before you send a signal

Check the PID and the full command line with ps -o pid,args. Polite first, -9 only if it does not react. Stop only processes you started yourself; killall stops every process with that name.

04Threads for waiting

A thread is a strand of work inside a process; all threads share its memory.

import threading, time

start = time.perf_counter()
threads = [threading.Thread(target=read_sensor, args=(name,))
           for name in sensors]
for t in threads:
    t.start()                  # all start, nobody waits yet
for t in threads:
    t.join()                   # now wait for every thread
elapsed = time.perf_counter() - start
print(f"Total time: {elapsed:.2f} s")

Pitfalls: target=read_sensor, not read_sensor(name) · args is a tuple: (name,) · join() in the first loop makes it sequential again.

05Processes for calculating

06Shared data and locks

Critical section: from reading shared data to writing it back. Without a lock, two threads can both read 10 and both write 11.

lock = threading.Lock()        # once, outside the function

def admit():
    global admitted
    with lock:                 # one thread at a time
        value = admitted
        admitted = value + 1

Deadlock: two threads each hold one lock and wait for the other. Rule: every thread takes the locks in the same order.
