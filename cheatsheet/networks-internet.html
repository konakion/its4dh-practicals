02Private or public

RangeMeaning

everything elsepublic: unique on the whole Internet

Private addresses are reused in every network; NAT replaces them on the way out (06). Special: 127.x.x.x loopback, 169.254.x.x self-assigned (no DHCP answer).

03Direct or via the gateway?

same network part → directlydifferent → default gateway

From 192.168.1.10/24: 192.168.1.20 (printer) → directly; 192.168.2.20 (Ward 4) → gateway: private, but another network; 192.0.2.80 (portal) → gateway. The gateway itself always has your network part.

04Packets

ping -c 2 192.168.1.10 2 received, 0% loss capture ping -c 1 192.0.2.80 course program (tcpdump) eth0 out 192.168.1.10 > 192.0.2.80 ttl=64 ICMP … ping -c 1 -t 3 HOST start with TTL 3

Header: source (where the reply goes), destination (read by every router), TTL. The content is never read by routers.

packets = ⌈ size ÷ 1,460 bytes ⌉

≈ 1,500 bytes per packet, ≈ 40 of them headers. X-ray 5,000,000 bytes → 3,424.7 → 3,425 packets. 300 bytes → 1 packet. Always round up.

“The portal does not open on this laptop”

1 Address? ip addr: 169.254 → no DHCP. 2 Way out? ip route, ping the gateway. 3 Name? nslookup vs. ping, and /etc/hosts. Works by address but not by name → step 3.

05Routing: one hop at a time

Each router looks up the destination network and hands the packet to the next hop. No router knows the whole path.

to 192.0.2.0/24 to 198.51.100.0/24 R1 → R2 R3 R2 → R5 R4 R3 → R4 R6 R4 → R5 R6 R5 → directly R4 R6 → R4 directly

Hospital → portal: R1 R2 R5. → university: R1 R3 R6. Line R2–R5 fails, R2 now says R4: R1 R2 R4 R5. Routers update their own tables (routing protocols); IP is best effort: packets can be lost, delayed or reordered.

TTL: two meanings

IP packet: a hop counter, lowered by one per router; at 0 the packet is dropped and an error goes back (traceroute uses this). 64 − 9 routers = 55. DNS record: how many seconds an answer may stay in a cache.

06NAT at the hospital router

inside (private) outside (public) 192.168.1.10:51000 ↔ 203.0.113.5:40001 192.168.1.37:52200 ↔ 203.0.113.5:40002

Out: private source → 203.0.113.5 and a free port, noted in the table. In: the port decides the device (40002 → nurses' PC). No entry (40999) → dropped: devices behind NAT cannot be called from outside. Not a firewall.

The recursive resolver walks root → TLD → authoritative for you and caches every answer for its TTL. “No answer” at the end of nslookup only means: no IPv6 address. NXDOMAIN: no such name.

/etc/hosts is checked first

A line there wins over DNS (nslookup ignores it, ping and browsers do not). Opens by address but not by name → look at name resolution: DNS or /etc/hosts. Remove a line: grep -v portal /etc/hosts > /tmp/h; cat /tmp/h > /etc/hosts
